# DSH Store Desktop 商城导航、审核说明与榜单标注复核

## 范围与依据

- 基于 `origin/main` Commit `fd31e8458b0b393b07380e30bef0b850273dfa6c`；源码包版本提升为 `0.9.33`。
- 用户要求商城导航使用剩余宽度、增加“官方插件”和“已安装插件”两个入口。此前还要求审核建议易懂、必装榜不要把大量补位项误显示成“第 1 名”，并授权操作测试、推送、发布与合并。
- 纠正原记录：源码 `0.9.33` 已由 PR [#1728](https://github.com/AI-Scarlett/DSH-Store/pull/1728) 合并，合并提交为 `8126cad644b8dad4336f4f7badf6204115039ac9`；Catalog 当时仍固定 `0.9.31`，因此 `.33` 尚未发布到 Desktop，也未在真实 Desktop 验收。

## 实现决定

| 决定 | 目标 | 好处 | 成本 | 证据 | 重新评估条件 |
| --- | --- | --- | --- | --- | --- |
| 导航使用自适应网格，并将最小按钮宽度设为 148px | 消除截图中按钮挤在左边、右侧留白过大的问题 | 宽窗口平铺可用空间；窄窗口自然换行；按钮文本允许换行 | 窄窗口会占用更多垂直空间 | Desktop 回归断言网格、auto-fit 和各按钮 100% 宽度；截图 UI 仍需真实 Desktop 验收 | Desktop 容器宽度、缩放或 Electron CSS 行为与测试 fixture 不同时 |
| 官方视图只展示 Desktop `pluginManager.listBundles()` 标记为 official、optional 或 `@deepseek-ai/*` 的已安装组件 | 让官方组件状态来自 DSH，而不是商城推测 | 只读呈现本机实际状态；不提供商城启停或卸载操作 | 该视图不代表 DSH 尚未安装的全部官方可选插件 | Fixture 覆盖官方插件与 `dsh.desktop-runtime`；官方清单不可用时显示不可核实状态 | DSH 官方管理器增加经过确认的完整官方可选插件目录 API 时 |
| 已安装视图只计入非官方组件，切换时清空旧筛选 | 避免官方组件与用户已安装插件混在一起，或被前一个视图的搜索条件隐藏 | 计数、列表、搜索状态相互一致 | 切换后需重新输入筛选条件 | Desktop 回归验证官方/用户列表分离、搜索过滤与清空切换 | 若产品决定让两个视图重叠展示所有安装组件时 |
| 审核建议默认给白话说明，完整扫描原因保留在折叠详情中 | 让普通用户先理解风险，同时保留可复核证据 | 常见文件、网络、命令、凭据、依赖、兼容性和发布结构信号有清楚解释 | 新类型原因会暂用通用解释并保留原文 | Desktop 回归覆盖网络和生命周期脚本建议、折叠原文、详情及确认界面 | 新扫描规则上线但尚未补充对应中文映射时 |
| 分类补位显示类别、可核对星标名次和未知星标数量 | 避免把“当前数据第 1 名”误读成分类冠军 | 缺数据时明确说冠军未确认；重复的第 1 名保留观察名次语义 | 标签更长，卡片可能多换一行 | 榜单模型与 Desktop 回归验证未知星标计数和新标签 | 榜单数据补齐所有分类星标后，可弱化未知数据提示 |

## 关键边界

- DSH Store 的审核解释、Catalog 状态与榜单只提供参考，不锁住确认后的安装请求；最终是否成功仍由 DSH Desktop 官方插件管理器返回。
- 官方视图只读展示 Desktop 当前报告的官方组件，不改 DSH 核心、不改 `@deepseek-ai/*`、不调用 Loader/Fiber，也不安装、卸载、启停或重启真实 Profile。
- 所有回归使用模拟 Desktop 管理器和一次性测试夹具；真实 Desktop 0.9.33 UI、目录滚动、搜索和管理器结果尚未验证。
