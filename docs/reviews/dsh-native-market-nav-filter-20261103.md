# DSH Desktop 商城导航与适配筛选修复

## 用户反馈

用户提供的 DSH Desktop 截图显示，主导航标签被平均拉伸到整行，最后的“本机插件”被挤到第二行；完整目录搜索栏没有 DSH Desktop 适配筛选。

## 原因

- `marketViewBar` 使用 `auto-fit` 与 `1fr`，浏览器将剩余宽度分配给所有导航列，使按钮变得过宽、间距失衡。
- Desktop 适配声明筛选只存在于“Catalog 审核记录 / 已安装插件”视图；完整目录、推荐榜和必装榜没有同一筛选。

## 修复

- 主导航改为左对齐、固定间距的 flex 标签组。标签使用稳定的最小宽度，不随剩余空间膨胀；窄窗口才换行。
- 选中“本机插件”时，把“官方插件”和“已安装插件”显示为独立、有边界的二级 Tab 组。
- 完整目录、推荐榜、必装榜恢复 Desktop 适配声明筛选，并展示各自视图中的数量。
- 筛选根据固定 Catalog 的 `compatibility.profiles` 判断。未声明适配显示为“未声明”，不代表不兼容；它不会改变 DSH Desktop 的安装判断。
