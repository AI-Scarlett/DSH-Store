01 / PRODUCT & TRUST

产品与信任

先确认 DSH STORE 是什么，以及“可信”在这里具体代表什么。

什么是 DSH STORE？＋

DSH STORE 是面向 DeepSeek Harness（DSH）的第三方插件商城与开发者入口，帮助用户发现插件、核对来源、权限和兼容性，并了解安全接入路径。

DSH STORE 是 DeepSeek 或 DSH 官方商城吗？＋

不是。DSH STORE 是第三方产品，不代表 DeepSeek 或 DSH 官方，也不会替换、隐藏或冒充官方插件清单。

插件被收录或标记为可安装，等于完成安全审计吗？＋

不等于。收录表示条目满足当前目录的固定来源、标准结构和策略检查；它不是完整的代码安全审计、运行验收或零风险承诺。

02 / INSTALL & PERMISSIONS

安装与权限

理解网页、DSH Profile 与真实插件变更之间的边界。

官网会直接修改我的 DSH Profile 或安装插件吗？＋

不会。浏览、搜索和查看详情默认只读。实际安装或启停需要在 DSH 中使用明确的命令或计划，并由用户确认。

安装插件前应该检查什么？＋

先确认插件能力是否符合需求，再检查固定来源、提交版本、权限、兼容性、维护状态和恢复说明；未知信息应保持为未知。

DSH STORE 如何展示插件权限？＋

目录会尽可能区分读取、写入、网络、凭据和生命周期能力，并说明用途与边界。无法由当前证据确认的权限不会被包装成已验证结论。

插件出现问题时如何停用或恢复？＋

使用 DSH 或插件管理器提供的明确停用路径，并保留安装前备份。真实变更应包含计划、前置哈希、健康检查和回滚；插件自身创建的数据需按其文档另行处理。

03 / CATALOG & BUILD

目录与开发

了解目录权威来源，以及插件提交和开发路径。

插件目录的数据来自哪里？＋

运行时目录权威来源是公开 GitHub 仓库中的 registry/catalog.json。插件源码使用固定提交引用，目录页面不会把临时搜索结果当作权威数据。

如何向 DSH STORE 提交插件？＋

通过 GitHub 的插件提交表单提供仓库、固定提交、清单、权限和兼容性信息。提交进入评审流程，不代表自动收录。

如何开发自己的 DSH 插件？＋

可以在开发插件页面安装开源 build-dsh-plugin Skill，用问题、目标结果和成功标准生成标准 Bundle、风险边界、测试和证据门槛。

04 / PRIVACY & SUPPORT

隐私与支持

确认网站收集什么，以及遇到问题时去哪里。

搜索插件会上传我的关键词吗？＋

不会。目录搜索、筛选和排序在浏览器本地完成。站点只记录有限的匿名交互事件，不发送搜索词、邮件地址或 Profile 内容。

遇到问题或希望合作，如何联系 DSH STORE？＋

可以发送邮件至 jadename.zhou@gmail.com，或通过 X 上的 @JadeNameCulture 联系。插件提交请优先使用 GitHub 提交表单。
