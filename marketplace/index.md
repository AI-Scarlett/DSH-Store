# DSH STORE

DSH STORE 是面向 DeepSeek Harness（DSH）的第三方插件商城。它帮助用户发现插件、核对来源与权限，并通过清楚、可恢复的路径把插件接入 DSH。DSH STORE 不代表 DeepSeek 或 DSH 官方，也不会替换、隐藏或冒充官方插件清单。

使用前，请先按实际需求查看插件的能力、来源、固定提交、权限、兼容性与维护状态。可安装条目指向固定的完整 Git Commit；文件、网络、命令和凭据边界会在操作前集中展示。浏览、搜索和查看详情默认只读，官网不会直接修改 DSH Profile 或安装插件。

真实变更需要在 DSH 内生成一次性计划并由用户确认。变更前应保留备份，变更后应完成健康检查；若执行失败，应恢复原始状态。DSH STORE 的收录或“可安装”状态不等于完整安全审计、运行验收或零风险承诺；无法核验的安全与兼容性信息保持未知。
