01 / WHAT IS A DSH PLUGIN?

什么是 DSH 插件？
What is a DSH plugin?

DSH 插件是为 DeepSeek Harness 提供额外能力的标准扩展。它可以连接工作流、工具、模型、界面或外部服务，但不同插件的权限和维护状态可能不同。

因此，商城不把“有页面”当成“可信”，也不把“可安装”当成完整安全审计。每个目录条目都应尽量展示公开仓库、固定 commit、版本、权限、兼容性和验证状态。

A plugin listing is a starting point, not a security guarantee. Check the pinned source, version, permissions, compatibility, maintenance and recovery path before you connect it to an agent.

FAQ / QUICK ANSWERS

关于 DSH 插件的快速回答

DSH STORE 是 DeepSeek 官方商城吗？ ＋

不是。DSH STORE 是第三方产品，不代表 DeepSeek 或 DSH 官方，也不会替换官方插件清单。

网页会直接安装插件或修改 Profile 吗？ ＋

不会。网页用于发现、阅读和复制信息；真实安装、启停或 Profile 变更需要在 DSH 中由用户确认。

Can I install a plugin from a search result alone? ＋

No. Use the catalog as a discovery layer, then verify the repository, pinned commit, manifest, permissions, compatibility and rollback instructions.
