02 / FROM BUILD TO DISCOVERY

从一个问题，到可复核的插件。

  1. 01写清问题、预期结果和成功标准
  2. 02构建标准 Bundle，并验证风险与权限
  3. 03固定 Commit 后提交，等待目录策略审查
  4. 04通过公开 Catalog 读回后，用户再独立决定是否安装

提交不代表自动收录；收录不等于安全审计或运行验收。真实安装和 Profile 变更仍由用户在 DSH 中决定。
